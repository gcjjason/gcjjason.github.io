# 防褥疮气垫床 · 产品概念设计研究报告

一份**单文件、零依赖**的交互式设计研究报告：把临床文献、市场竞品、多准则决策（MCDM）方法与三套产品概念，组织成一条可以直接往下读的论证链。

面向长期卧床患者的压疮风险问题，以临床文献为据、以人机工程学为尺，重新设计一台更安静、更安全、更少负担的交替充气气垫床，同时服务医院临床与居家护理两种场景。

- 主交付物：`index.html`（约 767 KB，图片全部 base64 内嵌，双击即开）
- 内容规模：11 章 · 约 26 屏 · 17 篇同行评议文献 / 7 款在售竞品
- 方法链：AHP + 熵权 + Kano 组合赋权 → Fuzzy-TOPSIS 与 VIKOR 交叉验证

---

## 快速开始

```bash
# 方式一：直接双击（无需任何环境）
open index.html          # macOS
start index.html         # Windows

# 方式二：本地静态服务（推荐，字体与锚点表现更稳定）
npx serve .
# 或
python -m http.server 8080
```

无构建步骤、无 npm 依赖、无 CDN 请求。现代 Chrome / Edge / Safari / Firefox 均可运行；移动端 Safari 与 Chrome 已适配。

| 功能    | 操作方式            | 说明                         |

## 设计系统

深色底 + 蓝紫为主，颜色承载语义而不是装饰。

| 角色         | 变量                | 值                     |
| ---------- | ----------------- | --------------------- |
| 页面底        | `--bg`            | `#070b13`             |
| 卡片面        | `--surface`       | `#101a2c`             |
| 正文         | `--txt`           | `#e9eff8`             |
| 次级文字       | `--txt-2`         | `#a8b8d0`             |
| 主数据 / 现状   | `--accent`        | `#4da3ff`             |
| 预测 / 智能新形态 | `--accent-2`      | `#7c5cff`             |
| 第二维属性      | `--cyan`          | `#35e0d0`             |
| 风险 / 严重度   | `--up` / `--warn` | `#ff4d4f` / `#ffb020` |

**数据配色规则**：蓝 = 主数据与现状，紫 = 预测与智能新形态，青 = 第二维属性，红橙 = 严重度与风险。同一种颜色不在同一页承担两种含义。

**字号**：正文段收敛为 10 档（11 / 12 / 13 / 14 / 15 / 16 / 17 / 18 / 20 / 22），24px 以上为展示级标题，按角色保留。圆角 10 / 16 / 22px 三级，缓动统一 `cubic-bezier(.22,.85,.28,1)`。

## 维护说明

**1. 保持单文件。** 8 张图片以 base64 内嵌（约 400 KB），换来「发一个文件就能看」的交付特性。拆成外部资源会破坏这一点，不要轻易做。

**2. 样式追加，不要就地改。** 新增调整建议以独立的 `<style id="...">` 块追加在 `</body>` 前，命名空间化（如 `.rvx-`、`.tmx-`）后与既有规则隔离，避免连带影响已验收的版式。

**3. 警惕外部编辑器回写。** 若用可视化编辑器打开并保存过这个文件，它会把运行时 DOM 固化进源码（`data-page-node-id` 属性、重复的导航操作组、光标探针、跑马带等），表现为按钮出现两份。清理脚本已留存：

```bash
node .taste-skill/strip-editor-artifacts.mjs   # 去掉 node-id 属性等标记
node .taste-skill/strip-baked-runtime.mjs      # 清掉烤入的运行时节点与重复图片
```

JS 侧已做幂等加固（元素已存在则复用），但清理后仍建议跑一遍上面的门禁。

**4. 改动前先备份。** 历史备份统一放 `.taste-skill/index.pre-*.html`，按阶段命名（`pre-type` / `pre-polish` / `pre-strip` …），出问题可逐级回退。

## 数据口径

- 市场数据截至 **2026 年 10 月**，人口口径按 2025 年末
- 市场规模取 **20–25 亿元保守窄口径**（家用出货占比 35%，交替充气技术路线占 72%）
- 概念方案价格为**目标价格带**，非报价，需以 BOM 实测校准
- 概念验证采用预测试 **n ≥ 30**，SUS 与规格实测为分层验证，不作为量产结论

报告内所有数字均可在对应章节找到来源标注；估算值、预测值与实测值分别有明确标识，不混用。
