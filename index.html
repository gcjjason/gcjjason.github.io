临床刚需

压力性损伤是长期卧床最主要的并发症之一，ICU 现患率高达 10.58%，预防是国际指南的强制性要求。

🔇

噪音是头号痛点

气泵 24 小时运行，噪音直接破坏患者睡眠与康复节律，用户反馈强度达到 5.0 / 5.0。

🧭

市场存在空白

主流价位集中在 200–500 元，而"静音 + 智能 + 可负担"三者兼具的产品在 300–600 元区间明显缺失。

03 / Design Directions

调研结论 → 设计启示

从六大痛点映射到可执行的设计方向，每一条都在回答同一个问题：这台床，到底应该长什么样。

🔇

静音优先

静音电机 + 陶瓷气阀 + 减振结构，实测噪音控制在 30 dB 内，远优于标准 45 dB 上限。

🔄

辅助翻身

在交替充气基础上增加侧向体位变换辅助，降低照护者操作力需求，缓解腰背职业损伤。

💧

微环境控制

微孔喷气 + 透气亲肤面料，兼顾减压、去湿、抗菌，改善皮肤微气候。

🎛️

交互简化

一键操作、状态可视化、漏气 / 断电异常报警，降低家属认知负荷。

🛡️

安全冗余

内置备电、CPR 快放、气囊独立可换，提升可靠性与应急能力。

🧩

模块化易维护

可拆卸气囊、防水耐磨面料、无死角结构，便于清洗消毒与维护。

研究边界：问卷样本量偏少，属探索性预调研，占比数据仅作趋势参考；结论已通过二手权威数据交叉验证。

04 / Methodology

多准则决策 MCDM 方法流

在文献与市场研究基础上，搭建一套从「指标构建→问卷调研→权重计算→方案排序→产品落地」的完整方法链， 用 AHP + 熵权 + Kano 主客观组合赋权，结合 Fuzzy-TOPSIS 与 VIKOR 交叉验证，最终通过 QFD 质量屋映射到工程特性，指导产品概念图设计。

Four-Stage Workflow

四阶段闭环 · 证据驱动的设计决策

1

指标构建阶段

文献编码 + 德尔菲专家咨询，提炼 C1–C7 七大准则 24 项子准则，形成初始评价体系。

2

问卷调研阶段

六模块问卷（A–H）覆盖人口学、Kano 双向、满意度、AHP 两两比较，分层抽样采集三类用户数据。

3

决策计算阶段

熵权（客观）+ AHP（主观）+ Kano（需求属性）综合赋权；Fuzzy-TOPSIS 主排序，VIKOR 交叉验证稳健性。

4

概念输出阶段

QFD 质量屋把用户需求权重映射为工程特性优先级，输出三套差异化产品概念图。

Eight Phases

八阶段详细工作流程

1

文献编码与指标初筛 输入

对 10 篇中文临床/工程文献与 17 篇英文临床文献做开放编码、主轴编码、选择性编码三级扎根分析，抽取初始设计要素。

  • 方法：扎根理论 + NVivo 编码
  • 输出：7 大准则、24 项子准则初始池
2

德尔菲专家咨询 方法

邀请 8–12 名专家（临床医师 3 / 康复护士 3 / 工业设计 2 / 医疗器械工程师 2）进行 2 轮函询，按"均值≥4 且变异系数<0.25"筛选指标。

  • 方法：德尔菲法 + Likert 5 级
  • 输出：经筛的正式评价指标体系（预计 20–24 项）
3

问卷设计与预测试 输出

六模块问卷（A 人口学甄别 / D 重要性 / E 满意度 / B Kano 双向 / H 开放题 / C AHP 专家卷 / F 候选方案模糊评价）；预测试 n≥30 做信效度检验。

  • 校验指标：Cronbach's α ≥ 0.7、KMO > 0.7、Bartlett 球形检验显著
  • 输出：正式发放版问卷
4

分层抽样与数据采集 输入

按"医院病房 100 + 居家护理 100 + 养老机构 50"分层抽样，目标 n≥200，确保三类用户（患者/家属/护士）均衡覆盖。

  • 渠道：南昌三甲医院康复科 + 社区居家护理中心 + 线上问卷星
  • 质控：答题时长 < 120 秒判无效、反向题一致性校验
5

组合权重计算 方法

三种权重融合：AHP 主观权重（专家判断矩阵）+ 熵权客观权重（样本离散度）+ Kano 调整系数（M/O/A/I/R 分类），最终权重 W = α·WAHP + β·WEntropy，并用 Kano 系数 k 对用户满意度进行非线性调整。

  • 一致性：AHP 矩阵 CR < 0.1 方为有效
  • 输出：24 项子准则最终权重
6

候选方案排序 方法

对 4 套候选方案（喷气式/交替式/翻身式/便携蓄电式）进行模糊语言评价，映射为三角模糊数，用 Fuzzy-TOPSIS 计算相对贴近度 Ci 做为主排序，再以 VIKOR 计算 Qi 做交叉验证，避免单一方法偏倚。

  • 稳健性：两种方法 Top-1 一致即接受；不一致则做敏感性分析
  • 输出：方案排序表 + 敏感性分析图
7

QFD 质量屋映射 方法

将用户需求（WHATs）×最终权重，映射到工程特性（HOWs：噪音值/气囊交替周期/翻身角度/面料透气率/续航时长/价格等），通过相关矩阵与自相关矩阵计算工程特性绝对权重。

  • 相关强度：◎=9 强相关 / ○=3 中相关 / △=1 弱相关
  • 输出：QFD 质量屋 + 工程特性优先级排序
8

产品概念图输出 输出

基于工程特性优先级，输出 3 套差异化产品概念图（旗舰智能型/居家经济型/便携转运型），每套包含外观效果图、功能爆炸图、关键交互界面。

  • 交付：概念图板 + 设计说明文档
  • 验证：概念图回到目标用户群做简易 SUS 可用性测试
05 / Criteria System

七大评价准则 · 24 项子准则

所有指标均源自临床文献与工程文献编码，保持与你既有方案编号一致（C1–C7），保证问卷数据可直接回灌计算模板。点击下方标签查看各准则详情。

AHP 专家两两比较（仅专家填写）

准则层 21 组 + 子准则层比较 · 1–9 标度 · 用于 AHP 主观权重

▾

▾

Layer Ⅰ · 权重层

组合赋权

主客观结合 + Kano 调整，避免单一方法偏差。
AHP 层次分析法专家 1–9 标度两两比较 → 主观权重 WAHP（CR < 0.1）
熵权法 Entropy基于问卷重要性评分的信息离散度 → 客观权重 WEnt
Kano 调整系数 kM=4 / O=2 / A=3 / I=0 / R 剔除；做非线性满意度放大
Layer Ⅱ · 排序层

方案综合评价

模糊集处理语言评价不确定性；双方法交叉验证稳健性。
Fuzzy-TOPSIS三角模糊数决策矩阵 → 加权规范化 → 相对贴近度 Ci（主排序）
VIKOR 交叉验证最大化群体效益、最小化遗憾 → Qi 折衷排序
敏感性分析权重扰动 ±10% 观察排序稳定性
Layer Ⅲ · 映射层

工程特性落地

把"用户语言"翻译成"工程师语言"，直接驱动设计。
QFD 质量屋WHATs × HOWs 相关矩阵 → 工程特性绝对权重排序
IPA 重要-绩效分析四象限定位优先改进区（高重要-低满意）
Better/Worse 系数识别魅力型属性作为差异化亮点
